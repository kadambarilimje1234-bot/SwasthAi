# 🩺 SwasthAI Sentinel

### AI-Powered Sepsis Early Detection & Patient Monitoring

🔗 **Live Demo:** https://swasthai-5.onrender.com/

SwasthAI Sentinel is an AI-powered healthcare system designed to help healthcare professionals **detect early signs of patient deterioration and sepsis risk** through continuous vital monitoring and intelligent alerts.

## 🚨 Problem

Sepsis can deteriorate rapidly, while many district hospitals lack ICU-grade continuous monitoring. Vital signs may be recorded only a few times a day, creating gaps where deterioration can go unnoticed.

## 💡 Solution

SwasthAI bridges this gap by:

* 📊 Monitoring vital signs
* 🤖 Predicting sepsis risk using Machine Learning
* 🚨 Generating early risk alerts
* 📈 Visualizing patient trends
* 🏥 Helping nurses prioritize high-risk patients

### 🔄 Workflow

```text
Patient
   ↓
Vital Signs
   ↓
AI/ML Prediction
   ↓
Sepsis Risk Score
   ↓
🟢 Stable | 🟡 Observe | 🔴 High Risk
   ↓
Early Alert → Healthcare Staff
```

## 🧠 AI

The prediction system analyzes clinical parameters such as:

* Heart Rate
* Blood Pressure
* Temperature
* SpO₂
* Respiratory Rate

The model generates a **risk score** to support early clinical assessment.

> ⚠️ This is a hackathon/research prototype and is **not a medical diagnostic device**.

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Recharts
**Backend:** Node.js, Express.js
**Database:** MongoDB
**AI/ML:** Python, Scikit-learn, XGBoost
**Deployment:** Render

## ✨ Key Features

* AI-based sepsis risk prediction
* Patient monitoring dashboard
* Vital-sign charts
* Risk prioritization
* High-risk alerts
* Patient history & analytics
* Responsive healthcare UI

## 🎯 Vision

> **Monitor → Predict → Alert → Act**

SwasthAI aims to reduce monitoring gaps and provide healthcare workers with an **early warning signal when a patient's condition may be deteriorating.**
